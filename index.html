Comment jouer

  • La bougie. Tout est dans le noir. Promène la flamme (souris ou doigt) : les numéros cachés n'apparaissent que dans sa lueur. Touche un numéro pour prendre la carte.
  • Les cartes. Elles s'alignent en bas. Touche-en une pour la lire. « Combiner » puis une autre carte pour les glisser l'une sur l'autre.
  • Les mécanismes. Cadenas, tableaux, orgue : ils s'ouvrent en grand. Une erreur rend le Reflet plus net.
  • L'iCoffin. Le Manuel de l'école, sur ton téléphone. Certains chapitres demandent un mot de passe, caché dans le jeu. Celui qui tient le téléphone lit à voix haute.
  • Le Reflet. Quand elle te regarde : ne bouge plus. Ni souris, ni doigt, et le téléphone face contre la table.
  • Minuit. Tu as 1 h 30. Les indices coûtent deux minutes.
